# C1-1 Jolokia 部署说明

## 1. 组件说明

客户内网 JVM 监控节点。老监控平台通过 Jolokia 的 HTTP 接口读取 JVM 指标，
现场按固定地址轮询，不经过 Nginx。

## 2. 版本与端口

| 项目 | 取值 |
| --- | --- |
| Java | JDK 17（`D:\develop\jdk-17.0.0.1`） |
| Spring Boot | 2.7.18 |
| Jolokia | 1.7.2（`org.jolokia:jolokia-core`，通过 Actuator 端点提供） |
| 服务端口 | 19301 |
| 健康检查 | `http://127.0.0.1:19301/actuator/health` |
| MBean 列表 | `http://127.0.0.1:19301/actuator/jolokia/list` |

Actuator 端点全部开放，Jolokia 端点位于 `/actuator/jolokia`。
日志通过 Logback 的 `JMXConfigurator` 注册到 JMX，列表中包含
`JMXConfigurator` 与 `reloadByURL` 操作。

## 3. 目录

| 用途 | 路径 |
| --- | --- |
| Maven 模块 | `src/C1/jolokia/` |
| 构建产物 | `runtime/C1/jolokia/jolokia.jar` |
| 运行目录 | `runtime/C1/jolokia/` |
| 日志 | `runtime/C1/jolokia/logs/jolokia.log` |
| 控制台日志 | `runtime/C1/jolokia/logs/console.log` |
| PID | `.state/C1-jolokia.pid` |

## 4. 配置

主配置：`src/C1/jolokia/src/main/resources/application.yml`

- `server.port`：19301
- `management.endpoints.web.exposure.include`：`*`
- `management.endpoint.jolokia.enabled`：`true`
- `logging.file.name`：`./logs/jolokia.log`

日志配置：`src/C1/jolokia/src/main/resources/logback-spring.xml`

## 5. 构建

```bat
cd /d C:\Users\HZR\Desktop\若依系统
mvn.cmd -s maven-settings.xml -Dmaven.repo.local=.m2 -f src\C1\jolokia\pom.xml clean package -DskipTests
copy /Y src\C1\jolokia\target\jolokia.jar runtime\C1\jolokia\jolokia.jar
```

## 6. 启动与停止

```bat
python scripts\components_start.py jolokia
python scripts\components_stop.py jolokia
```

启动脚本使用 `subprocess.Popen(close_fds=True, creationflags=CREATE_NEW_PROCESS_GROUP|DETACHED_PROCESS)`
拉起进程，PID 写入 `.state/C1-jolokia.pid`，随后探测 `/actuator/health`。
