# C1-3 内部数据服务部署说明

## 1. 组件说明

内部客户与订单数据服务。使用 Spring Data REST 暴露 `Customer`、`Order` 两个实体，
上游客户门户按 `/api` 地址读取数据。演示数据在启动时写入 H2 内存库。

## 2. 版本与端口

| 项目 | 取值 |
| --- | --- |
| Java | JDK 17（`D:\develop\jdk-17.0.0.1`） |
| Spring Boot | 2.7.18 |
| Spring Data JPA | 2.7.18（Spring Boot 管理） |
| Spring Data REST | 3.7.18（Spring Boot 管理） |
| H2 | 2.1.214 |
| 服务端口 | 19303 |
| 根入口 | `http://127.0.0.1:19303/api` |
| 客户列表 | `http://127.0.0.1:19303/api/customers` |
| 订单列表 | `http://127.0.0.1:19303/api/orders` |

## 3. 目录

| 用途 | 路径 |
| --- | --- |
| Maven 模块 | `src/C1/data-service/` |
| 构建产物 | `runtime/C1/data-service/data-service.jar` |
| 运行目录 | `runtime/C1/data-service/` |
| 日志 | `runtime/C1/data-service/logs/data-service.log` |
| 控制台日志 | `runtime/C1/data-service/logs/console.log` |
| PID | `.state/C1-data-service.pid` |

## 4. 配置

主配置：`src/C1/data-service/src/main/resources/application.yml`

- `server.port`：19303
- `spring.data.rest.base-path`：`/api`
- `spring.data.rest.default-page-size`：20
- `spring.jpa.hibernate.ddl-auto`：`create-drop`
- 数据源：`jdbc:h2:mem:customer_center`，用户 `sa`，空密码
- `logging.file.name`：`./logs/data-service.log`

## 5. 演示数据

启动时由 `DataInitializer` 写入：

- 20 家客户，中文公司名，统一社会信用代码为 18 位格式
- 30 张订单，订单号格式 `SO + yyyyMMdd + 4 位序号`
- 金额保留两位小数
- `create_time` 分布在 2023-01-01 至 2026-10-29 之间

## 6. 构建

```bat
cd /d C:\Users\HZR\Desktop\若依系统
mvn.cmd -s maven-settings.xml -Dmaven.repo.local=.m2 -f src\C1\data-service\pom.xml clean package -DskipTests
copy /Y src\C1\data-service\target\data-service.jar runtime\C1\data-service\data-service.jar
```

## 7. 启动与停止

```bat
python scripts\components_start.py data-service
python scripts\components_stop.py data-service
```

启动脚本使用独立进程方式拉起 jar，PID 写入 `.state/C1-data-service.pid`，
随后探测 `/api` 根入口。
