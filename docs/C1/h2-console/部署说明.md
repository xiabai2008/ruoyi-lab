# C1-2 H2 Console 部署说明

## 1. 组件说明

演示用 H2 内存库控制台。控制台开启并允许远程访问，演示数据随进程启动重建，
进程停止后内存数据清空。

## 2. 版本与端口

| 项目 | 取值 |
| --- | --- |
| Java | JDK 17（`D:\develop\jdk-17.0.0.1`） |
| Spring Boot | 2.7.18 |
| H2 | 2.1.214 |
| 服务端口 | 19302 |
| 控制台地址 | `http://127.0.0.1:19302/h2-console` |

## 3. 目录

| 用途 | 路径 |
| --- | --- |
| Maven 模块 | `src/C1/h2-console/` |
| 构建产物 | `runtime/C1/h2-console/h2-console.jar` |
| 运行目录 | `runtime/C1/h2-console/` |
| 日志 | `runtime/C1/h2-console/logs/h2-console.log` |
| 控制台日志 | `runtime/C1/h2-console/logs/console.log` |
| PID | `.state/C1-h2-console.pid` |

## 4. 配置

主配置：`src/C1/h2-console/src/main/resources/application.yml`

- `server.port`：19302
- `spring.h2.console.enabled`：`true`
- `spring.h2.console.path`：`/h2-console`
- `spring.h2.console.settings.web-allow-others`：`true`
- 数据源：`jdbc:h2:mem:opsdemo`，用户 `sa`，空密码
- `logging.file.name`：`./logs/h2-console.log`

## 5. 构建

```bat
cd /d <工程根>
mvn.cmd -s maven-settings.xml -Dmaven.repo.local=.m2 -f src\C1\h2-console\pom.xml clean package -DskipTests
copy /Y src\C1\h2-console\target\h2-console.jar runtime\C1\h2-console\h2-console.jar
```

## 6. 启动与停止

```bat
python scripts\components_start.py h2-console
python scripts\components_stop.py h2-console
```

启动脚本使用独立进程方式拉起 jar，PID 写入 `.state/C1-h2-console.pid`，
随后探测 `/h2-console` 页面。
