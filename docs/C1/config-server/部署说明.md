# C1-4 配置中心部署说明

## 1. 组件说明

Spring Cloud Config Server，使用 native 后端读取本机 `config` 目录。
客户内网业务服务通过 `/application/{profile}`、`/{application}/{profile}` 拉取配置。

## 2. 版本与端口

| 项目 | 取值 |
| --- | --- |
| Java | JDK 17（`D:\develop\jdk-17.0.0.1`） |
| Spring Boot | 2.7.18 |
| Spring Cloud | 2021.0.8 |
| Spring Cloud Config Server | 3.1.8 |
| 服务端口 | 19304 |
| 默认配置 | `http://127.0.0.1:19304/application/default` |
| 生产配置 | `http://127.0.0.1:19304/application/prod` |
| 业务配置 | `http://127.0.0.1:19304/customer-service/default` |

## 3. 目录

| 用途 | 路径 |
| --- | --- |
| Maven 模块 | `src/C1/config-server/` |
| 配置源目录 | `src/C1/config-server/config/` |
| 构建产物 | `runtime/C1/config-server/config-server.jar` |
| 运行时配置目录 | `runtime/C1/config-server/config/` |
| 运行目录 | `runtime/C1/config-server/` |
| 日志 | `runtime/C1/config-server/logs/config-server.log` |
| 控制台日志 | `runtime/C1/config-server/logs/console.log` |
| PID | `.state/C1-config-server.pid` |

## 4. 配置文件

`config` 目录包含 3 个文件：

| 文件 | 内容 |
| --- | --- |
| `application.yml` | 数据库连接、Redis、服务编码、功能开关 |
| `application-prod.yml` | 生产库地址、连接池、生产区开关、日志级别 |
| `customer-service.yml` | 客户服务中心名称、同步任务、通知渠道、导入开关 |

数据库与 Redis 均为示例地址，密码使用示例占位值，不包含现场真实口令。

## 5. 配置

主配置：`src/C1/config-server/src/main/resources/application.yml`

- `server.port`：19304
- `spring.profiles.active`：`native`
- `spring.cloud.config.server.native.search-locations`：`file:./config/`
- `logging.file.name`：`./logs/config-server.log`

## 6. 构建

```bat
cd /d <工程根>
mvn.cmd -s maven-settings.xml -Dmaven.repo.local=.m2 -f src\C1\config-server\pom.xml clean package -DskipTests
copy /Y src\C1\config-server\target\config-server.jar runtime\C1\config-server\config-server.jar
xcopy /E /I /Y src\C1\config-server\config runtime\C1\config-server\config
```

## 7. 启动与停止

```bat
python scripts\components_start.py config-server
python scripts\components_stop.py config-server
```

启动脚本使用独立进程方式拉起 jar，工作目录为 `runtime/C1/config-server/`，
因此 native 后端读取同目录下的 `config`。PID 写入 `.state/C1-config-server.pid`，
随后探测 `/application/default`。
