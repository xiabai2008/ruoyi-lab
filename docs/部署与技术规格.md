## 四、数据库

**绝对禁止**使用宿主机的 MySQL 3306。用独立实例：

| 项 | 值 |
|---|---|
| 端口 | 13307 |
| datadir | `mysql\data` |
| root 口令 | 空（`--initialize-insecure`） |
| 字符集 | `utf8mb4` / `utf8mb4_general_ci` |
| 库名 | `ry_r1` ~ `ry_r12` |

初始化：`mysqld --initialize-insecure --datadir=...`，首次启动后建库、导官方 SQL、导 seed。

**停止实例只能按端口找 PID 再 kill**：

```bat
netstat -ano | findstr :13307
taskkill /PID <pid> /F
```

禁止 `taskkill /F /IM mysqld.exe`（会连宿主库一起杀）。

## 五、Redis

**R1~R5 不需要 Redis。** RuoYi 4.x 单机版用 session 内存，没有 Redis 依赖。第一批、第二批全部跳过这一节。

R6 之后才需要：

| 项 | 值 |
|---|---|
| 端口 | 6379（若被占用则 16379，写进 toolchain.md） |
| 配置 | `requirepass` 按站点区分：R6 R9 有密码，R7 无密码（这是站点设定，不是疏漏） |
| db 分配 | R6→0, R7→1, R8→2, R9→3 |

R7 的「无密码」是站点特性，**不要**为了统一而加密码。

装法：Windows 便携版（`redis-server.exe` + `redis.windows.conf`）解压到项目 `redis\` 目录，不装服务、不动系统 PATH。到 R6 之前再装。

## 六、Nginx

Windows 版 nginx，所有站点对外入口都走它（这样 `Server` 头才是 `nginx/x.x.x`，像真的一样）。

**装法**：从 nginx.org 下 Windows 稳定版 zip（1.24.x 或 1.26.x），解压到项目 `nginx\` 目录，不装服务、不动系统 PATH。这是必需组件，**第一批就要装好**。

如果 nginx.org 下载慢，用国内镜像，或从其他机器拷一份 `nginx.exe` + `conf\` + `html\` + `logs\` 目录过来。版本号写进 `toolchain.md`。

目录约定：

```
nginx\
├── nginx.exe
├── conf\nginx.conf       # 主配置，include conf.d/*.conf
├── conf.d\R1.conf ...
├── html\                 # 静态资源、错误页
└── logs\                 # access.log / error.log
```

每个站点一个 `conf.d\Rxx.conf`，统一结构：

```nginx
server {
    listen 19102;
    server_name 127.0.0.1;
    client_max_body_size 100m;

    access_log logs/R2_access.log main;

    location / {
        proxy_pass http://127.0.0.1:19202;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Vue 站点（R6 R7）额外加：

```nginx
location / { root html/R6; try_files $uri $uri/ /index.html; }
location /prod-api/ { proxy_pass http://127.0.0.1:19206/; }
```

R12 在 R2 的 server 块里加拦截规则（模拟 WAF），配置见 `docs\站点清单.md` 的 R12 条目。

HTTPS：给 R3 R5 R6 三个站点配 443 等价端口（19103→19443 等），用内部 CA 签的证书。

## 八、启停脚本规范

所有脚本放 `scripts\`，接受站点编号作参数（`03_start.bat R2`）。

`03_start.bat` 必须做四件事：
1. 校验端口空闲
2. 校验 jar 存在（不存在提示先跑 01_build）
3. 用 `start /B` 或 `javaw` 后台起，输出重定向到 `runtime\Rxx\run.log`
4. 轮询 `/login` 最多 90 秒，返回 200 且含"登录若依系统"才算起来；通了才返回成功，PID 写进 `.state\Rxx.pid`
   （单机版没有 actuator，别拿 `/actuator/health` 探活）

`04_stop.bat` 只 kill `.state\Rxx.pid` 里记的 PID，不要按映像名 `taskkill /IM java.exe`（会把别的站点一起杀掉）。

`05_health.bat` 遍历 12 个站点，输出表格：编号 / 端口 / HTTP 状态 / 登录页是否含版权年份 / 响应耗时。

## 九、构建顺序与依赖

必须先起基础组件再起应用：

```
MySQL(13307) → Redis(6379) → [Nacos(18848) 仅 R8] → 各后端 → Nginx
```

R8 的 Cloud 额外顺序：Nacos → 各微服务注册 → Gateway。
