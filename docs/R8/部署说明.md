```bat

python scripts\start_r8_cloud.py status
```

## 已知偏差

### 网关 Redis 健康子项

- 现象：`GET http://127.0.0.1:19208/actuator/health` 曾返回 `DOWN`，子项为
  `redis: Cannot read Redis info`。
- 定位：`redis-cli -a ruoyi123 -n 2 INFO` 正常；业务读写正常；网关日志无 NOAUTH / WRONGPASS / timeout，
  仅 `Spring Data Redis` 的 `Converters.toProperties` 在解析 Windows 版 Redis 5.0.14 的 INFO 响应时失败。
- 处置：在 Nacos `ruoyi-gateway-dev.yml` 的 `management.health.redis.enabled` 设为 `false`，
  并保留注释说明原因。只关闭 Redis 健康子项，其他健康检查（db/disk/discovery/liveness/readiness 等）保持开启。
- 结果：`/actuator/health` 返回 `status: UP`，`/actuator/gateway/routes` 仍为 200，业务接口正常。
